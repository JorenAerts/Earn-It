# Glossary

One fixed word per language, so the app reads consistently. "Gloop", "Gloop Pro", "Buddies", "XP",
"Rise & Conquer" and the Apple product names are never translated. Apple UI names (Focus, Settings,
Lock Screen, snooze button) follow Apple's own wording in that language.

## Style rules (all languages)
- **Gender: the usual masculine default** for the reader ("réveillé", "despierto", "sveglio",
  "acordado", "un ami"), as most apps do. No neutral rewrites, no "·e" / "o/a" notation.
  Gloop itself is grammatically masculine ("le Gloop", "o Gloop").
- **User-typed item names** have an unknown grammatical gender: quote them („%@“, « %@ », «%@»)
  instead of "deinen %@" / "ton %@".
- **No calques.** Translate the meaning, not the words ("keep you going" → "houden je gemotiveerd",
  not "houden je gaande").
- **pt-PT is not pt-BR.** Check vocabulary (telemóvel, ecrã, casa de banho, registar, digitalizar,
  equipa, ginásio, saltar) and grammar (enclitic pronouns: "deixa-me", "cole-o"; "a sua", "por si").
- **French typography:** non-breaking space (U+00A0) before ? ! : ; and inside « », typographic
  apostrophe ’.
- **Quotes:** „…“ (de), « … » (fr), «…» (es, it), “…” (pt). Don't put quote marks in keys; add them
  in the translation.
